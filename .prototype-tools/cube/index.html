A face rosa é a pista. Desenhe as outras cinco arestas visíveis para formar um cubo em perspectiva. Não é necessário desenhar as linhas escondidas atrás dele.

Nos dois aquecimentos do desafio clássico e no tutorial, as arestas pontilhadas ajudam a construir o volume. Use o botão de apoio para mostrar ou ocultar. Os aquecimentos não entram na pontuação da sessão.

  1. Observe a inclinação e o tamanho da face. O ponto vermelho é um vértice do cubo: três arestas se encontram exatamente nele.
  2. Arraste para desenhar. Use Reta para ligar dois pontos ou Apagar para remover um traço.
  3. Clique em Avaliar desenho. Compare seu desenho vermelho com a solução azul. No treino, explore as linhas de fuga.

As arestas do cubo têm o mesmo comprimento em 3D, mas parecem diferentes na perspectiva. A nota mede proximidade e cobertura das linhas esperadas; é uma orientação para praticar.

Personalize os atalhos na página inicial do Treino do Olhar. Para usar o botão lateral da caneta, configure-o no driver para enviar a tecla escolhida.
