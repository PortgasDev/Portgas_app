FORMAS E INTERVALOS

XUIM ART · FUNDAMENTO PARA IMAGINAR.Sem cronômetro · funciona offline

Compare antes de corrigir.

As formas ocupadas são o espaço positivo. Os intervalos e as aberturas são o espaço negativo. Os dois ajudam a enxergar proporção.

  1. Escolha uma forma na cópia, arraste para posicionar e ajuste largura e altura. A primeira forma fica fixa como base.
  2. Ative Ver espaços vazios para destacar o fundo e as aberturas em azul. Observe seus contornos.
  3. Em Medir dois pontos, toque em duas posições da referência. Essa distância vira X. Use Transportar X e arraste a barra na cópia. Gire pela ponta; o tamanho não muda.
  4. Compare para revelar a referência tracejada, leia uma orientação por forma e tente de novo.

O compasso é opcional. Para operar por teclado, use os botões de ajuste; no modo de medida, Tab encontra os controles de cada ponto. A proporção dos objetos é comparada dentro do mesmo enquadramento.
